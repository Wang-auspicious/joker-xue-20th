## 📝 作业要求

### 一、数据获取与预处理（15分）

- [ ] 爬取、读取并理解数据集结构
- [ ] 数据清洗：去除重复评论、空白评论、广告/无意义内容（如纯标点、纯表情）
- [ ] 中文分词：使用对评论文本进行分词
- [ ] 去除停用词：加载停用词表，过滤高频无意义词
- [ ] 记录预处理前后的数据量变化

### 二、基础统计可视化（20分）

必须完成以下至少 **2项** 基础统计可视化：

**A. 评论长度分布**
- 统计每条评论的字数/词数
- 绘制直方图 + 核密度曲线（KDE）
- 分析：评论长度主要集中在什么范围？

**B. 点赞数分布**
- 绘制点赞数的箱线图或直方图（建议对数坐标）
- 标注点赞数最高的前 5 条评论内容
- 分析：高赞评论有什么共同特征？

**C. 评论时间分布**
- 按小时/日/月统计评论数量
- 绘制时间序列折线图
- 分析：什么时间段评论最活跃？

**D. 高频用户分析**
- 统计评论数量最多的前 10 名用户
- 绘制水平柱状图
- 分析：高频用户的行为模式

### 三、词云与关键词分析（25分）

- [ ] 生成**全量评论词云图**
- [ ] 提取 Top 30 高频词，绘制**水平条形图**或**词林图**
- [ ] 分别对**高赞评论**（like_count ≥ 中位数）和**普通评论**生成对比词云
- [ ] 分析：高频词反映了哪些主题？高低赞评论的用词有何差异？

**词云要求**：
- 自定义配色方案（推荐使用歌曲/歌手主题色）
- 设置形状遮罩（加分项，如使用心形、音符等形状）
- 中文字体需正确渲染（需指定中文字体路径）
- 尽可能保留提示词优化过程

### 四、情感分析可视化（25分）

- [ ] 使用 `snownlp` 对每条评论进行情感打分（0~1分）
- [ ] 将情感分为三类：积极（>0.6）、中性（0.4~0.6）、消极（<0.4）
- [ ] 绘制**情感分布饼图/环形图**
- [ ] 绘制**情感随时间变化趋势图**（折线图或堆叠面积图）
- [ ] 选取积极和消极评论各 3~5 条典型示例展示

**分析要求**：
- 该歌曲评论区整体情感倾向如何？
- 情感极性是否随时间有变化趋势？
- 高赞评论的情感倾向有无明显特征？

### 五、分析与总结报告（15分）

撰写一份完整的分析报告，包含以下内容（不少于 400 字）：

1. **数据概况**：你选择了哪首歌？数据量、时间范围等
2. **主要发现**：通过可视化你发现了哪些有趣的模式或现象？
3. **评论文化观察**：从评论区能看出什么样的"云村"文化特点？
4. **不足与改进**：本次分析的局限性，如果给你更多时间会如何改进？

## 💡 参考思路与技巧

### 数据清洗方面
```python
# 去除重复评论
df = df.drop_duplicates(subset=['content'])

# 去除短评论（少于2个字符）
df = df[df['content'].str.len() >= 2]

# 中文分词
import jieba
df['words'] = df['content'].apply(lambda x: ' '.join(jieba.cut(x)))
```

### 情感分析
```python
from snownlp import SnowNLP

def get_sentiment(text):
    try:
        s = SnowNLP(text)
        return s.sentiments
    except:
        return 0.5

df['sentiment'] = df['content'].apply(get_sentiment)
```

### 交互式情感时间序列（加分项）

## ❓ 常见问题

**Q: 分词结果不准确怎么办？**
A: 可以加载自定义词典（`jieba.load_userdict('dict.txt')`），或者对特定领域词汇（如歌曲名、歌手名）进行强制分词。

**Q: snownlp 情感分析准确吗？**
A: snownlp 对中文评论有一定的准确度，但并非完美。可以结合规则（如表情符号、感叹号数量）辅助判断。

**Q: 可以只分析一首歌吗？**
A: 可以，选择数据量最大的一首即可。多歌曲对比为加分项。

**Q: 报告必须用模板吗？**
A: 必须使用提供的 `Homework2_Solution_Template.md` 填写，可适当调整格式。
